# Maven
Maven è uno strumento di build automation, utilizzato prevalentemente nella gestione dei progetti Java. Attraverso la build automation si riduce il carico di lavoro. Alcune delle fasi fondamentali che vengono automatizzate sono:
- compilazione in codice binario
- packaging dei binari
- esecuzione dei test per garantire il funzionamento del software
- deployment dei sistemi
- documentazione relativa al progetto portato a termine

# Spring
Lo spring inizialazer è la base per lo sviluppo del progetto.

# Postman
Postman serve ad interrogare il server ed a verificare il corretto funzionamento, utile per testing. La risposta è una stringa JSON
