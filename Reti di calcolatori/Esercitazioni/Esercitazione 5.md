# Web Server e web application
Un web server è il processo che tipicamente viene utilizzato da una macchina server per rendere disponibili i web services. Una web application è una collezione di risorse web che deve rispettare un certo standard, ossia deve essere organizzata in una determinata gerarchia di cartelle. Per ogni applicazione deve essere creata una cartella (MyWebApplication) contenente tuttte le sue risorse. Le risorse devono necessariamente comprendere una cartella di nome WEB-INF, all'interno della quale sono contenute tutte le risorse private non accessibili direttamente dal web. La cartella deve inoltre contenere il file web.xml, necessario all'inizializzazione dell'applicazione, una cartella classes che conterrà i file .class della applicazione ed un'eventuale cartella lib con le librerie esterne. Tutto ciò che deve essere accessibile dall'utente deve essere messo direttamente nella cartella principale dell'applicazione, infine la cartella MyWebApplication può essere posizionata all'interno della cartella webapps di Tomcat, in modo da avere un deploy automatico.

Apache Axis fornisce un tool che a partire da un file WSDL di ottenere un'applicazione Java, con tutte le chiamate ad un web service ma anche un tool che a partire dal codice Java estrae il file WSDL in xml.
